# AyuDiet Connect

A browser based front end demo for Ayurvedic diet planning.

## Run it

Open `index.html` in a browser. No build step is required.

The demo stores fictional patient profiles and meal plans in the browser's local storage. Nutrition values and Ayurvedic attributes are sample records for the demonstration.

## Files

- `index.html` contains the page structure.
- `style.css` contains layout, responsive styling, and print styling.
- `app.js` contains the meal editor, calculations, approval, and print behavior.
- `assets/` contains the local photo, fonts, animation scripts, and license files.

## Team workflow

Use a shared GitHub repository. Each contributor should create a branch, commit and push their changes, then open a pull request for review before merging.
